# PSO 5,000회 × 초기장별 25 seed 추가 실험

기존 seed 1 네 건을 보존하고 seed 2–25의 96건을 추가했다. 실패·제외는 0건이다. 원래 PSO 코드가 아닌 동일 시뮬레이터 위 재구현의 평가이며, 기존 Stage 5 결과는 보존했다.

## 검증과 해석

- 100개 장시간 실행 모두 500회 시점의 예산·분산이 기존 동일 seed의 500회 결과와 일치했다. 즉 같은 탐색의 연장이며, 설정을 바꾼 비교가 아니다.
- 장시간 실행 100건 중 89건은 정확히 목표 예산, 나머지 11건은 목표 예산보다 1회 많은 예산으로 끝났다. 모든 예산은 기존 40개 검증 사례에 포함됐다.
- 40개 하한·상한과 200개 PSO 배분의 목적값을 정확 산술로 재평가하고, 별도의 표준 라이브러리 구현으로 모두 재검산했다. PSO가 최선 incumbent를 개선한 예산은 없었다.
- 같은 seed의 500회와 5,000회를 비교하면 100쌍 모두 각자의 최종 예산에서 계산한 정규화 초과분이 감소했다. 두 실행의 최종 예산은 다를 수 있다.
- 표본 중앙값의 좁은 구간은 정수 최적값에 대한 수학적 포함구간이다. 마지막 열은 독립 실행 가정 아래 모집단 중앙값을 추정하는 주변적 95.67% 신뢰구간이며, 네 환경에 대한 동시 보장이 아니다.
- 기존 seed 1의 center-100 초과분 약 54.6%는 새 표본 중앙값 약 66.9%보다 낮았다. 28–55%라는 기존 장시간 실행 요약을 새 중앙값 약 27–67%로 교체해야 한다.
- 500회 결과 및 Stage 9 사전 고정 표본·보장은 변경하지 않았다. 추가 실험은 기존 결과를 본 뒤 정한 후속 분석이다.

## 파일

- `protocol.json`: 실행 전 목록·설정·입력/코드 해시
- `runs/`, `alloc/`, `history/`: 실행별 결과·배분·이력
- `analysis.json`: 정확 초과분과 집계
- `witness/`, `operator.json`, `inputs/`: 재검산 입력
- `verification.json`: 독립 정확 계산 결과
- `prefix500_checks.json`: 동일 seed의 500회 시점 대조

## 재실행

`experiments` 폴더에서:

```bash
.venv/bin/python pipeline/stage5_long_runs.py
.venv/bin/python pipeline/stage5_long_analyze.py
python3 pipeline/verify_stage5_long25.py
.venv/bin/python pipeline/stage5_long_report.py
```

첫 명령은 코드·입력 해시를 확인하고 완료된 실행을 재사용한다. 기존 결과 파일을 삭제하지 않고 이어서 실행한다. 공개 폴더·GitHub 업로드는 이 실행에 포함하지 않는다.
