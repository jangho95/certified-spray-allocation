# PSO 장시간 실행 비교

네 초기장 각각에 시드 25개를 사용해 PSO의 500회와 5,000회 결과를 비교했다. 기존 시드 1 실행 네 건에 96건을 추가했으며, 실패하거나 제외된 실행은 없었다. PSO는 해당 시뮬레이터에서 재구현했다.

| 초기장 | 500회 표본 중앙값 구간 (%) | 5,000회 표본 중앙값 구간 (%) | 5,000회 실행 범위 (%) | 5,000회 모집단 중앙값 신뢰구간 (%) |
|---|---:|---:|---:|---:|
| Zero | [102.6, 102.8] | [38.9, 39.1] | [30.2, 45.2] | [36.8, 41.5] |
| Random | [59.9, 60.1] | [26.6, 26.8] | [23.4, 32.6] | [25.9, 28.0] |
| Center-30 | [121.4, 121.7] | [46.2, 46.4] | [38.3, 56.8] | [44.8, 49.1] |
| Center-100 | [148.3, 148.5] | [66.8, 67.0] | [51.1, 82.8] | [62.6, 73.3] |

## 검증과 해석

- 100개 장시간 실행 모두 500회 시점의 예산·분산이 기존 동일 seed의 500회 결과와 일치했다. 즉 같은 탐색의 연장이며, 설정을 바꾼 비교가 아니다.
- 장시간 실행 100건 중 89건은 정확히 목표 예산, 나머지 11건은 목표 예산보다 1회 많은 예산으로 끝났다. 모든 예산은 기존 40개 검증 사례에 포함됐다.
- 40개 하한·상한과 200개 PSO 배분의 목적값을 정확 산술로 재평가하고, 별도의 표준 라이브러리 구현으로 모두 재검산했다. PSO가 최선 incumbent를 개선한 예산은 없었다.
- 같은 seed의 500회와 5,000회를 비교하면 100쌍 모두 각자의 최종 예산에서 계산한 정규화 초과분이 감소했다. 두 실행의 최종 예산은 다를 수 있다.
- 표본 중앙값의 좁은 구간은 정수 최적값에 대한 수학적 포함구간이다. 마지막 열은 독립 실행 가정 아래 모집단 중앙값을 추정하는 주변적 95.67% 신뢰구간이며, 네 환경에 대한 동시 보장이 아니다.
- Center-100에서 시드 1의 초과분은 약 54.6%였고, 25회 표본의 중앙값은 약 66.9%였다.
- 장시간 실행은 기존 결과를 바탕으로 설계한 후속 실험이다.

## 파일

- `protocol.json`: 실행 전 목록·설정·입력/코드 해시
- `runs/`, `alloc/`, `history/`: 실행별 결과·배분·이력
- `analysis.json`: 정확 초과분과 집계
- `witness/`, `operator.json`, `inputs/`: 재검산 입력
- `verification.json`: 독립 정확 계산 결과
- `prefix500_checks.json`: 동일 seed의 500회 시점 대조

## 검증과 재실행

[실행 환경](../../README_ko.md)을 설정한 뒤 저장소 루트에서 실행한다.

```bash
python verification/verify_certificates.py --suite stage5_long25
```

실험을 다시 실행하려면 다음 명령으로 새 작업 사본을 만든다.

```bash
python tools/new_run.py ../spray-pso-replay --build --stage pso-long
```

재실행은 기존 시드 1 장시간 실행 네 건을 사용하고, 나머지 96건을 다시 계산한다. 단계별 절차는 [재현 안내](../../docs/REPRODUCING.md)에 있다.
